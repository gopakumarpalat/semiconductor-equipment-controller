# Semiconductor Equipment Controller

A C-based semiconductor equipment control software simulator.

## Current Features

- Equipment state management
- IDLE state
- READY state
- RUNNING state

## Planned Features

- Robot control
- Chamber control
- Sensor management
- Alarm management
- Logging
- Multithreading
- IPC
- TCP/IP communication
- SECS/GEM
- EDA concepts
- Bash automation
